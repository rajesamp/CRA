# RAG corpus

Documents that ChangeRiskAdvisor retrieves from (task #7). All content is
synthetic or summarised from the course sample; no real incident records or
customer data. Each file starts with front matter (doc type, incident ID,
service, change type, severity, source) that becomes chunk metadata.

| Folder | Documents | Contents |
|---|---|---|
| `postmortems/` | 10 | Detailed postmortems: INC-2201 (summarised from the course sample postmortem), plus INC-1987, INC-2055, INC-2214, INC-2233, INC-2248, INC-2255, INC-2289, INC-2318, INC-2325 |
| `incidents/` | 20 | One summary per incident in `data/incidents.json`, generated by `scripts/build_incident_summaries.py` |
| `runbooks/` | 10 | Change review checklist, approval policy, freeze-window policy, high-risk services policy, dependency-graph guide, and runbooks for timeouts, dependency upgrades, feature flags, schema migrations, and capacity changes |
| **Total** | **40** | Ingested as 72 chunks (see `docs/evidence/ingestion-log.md`) |

## Coverage of the six sample queries (requirements.md)

| # | Sample query | Documents that cover it | Top-3 retrieval check |
|---|---|---|---|
| 1 | How risky is this change to the checkout-service config? | Postmortems INC-2201, INC-2289; `runbooks/timeouts-and-retries.md`; `runbooks/change-review-checklist.md` | INC-2201 ranks 1st |
| 2 | Have we had incidents from similar changes before? | All 20 incident summaries and 10 postmortems, each tagged by service and change type | Depends on the change described; the agent asks which change if none is given |
| 3 | Is this a freeze window right now? | `runbooks/freeze-window-policy.md` (status itself must come from the system-health tool) | freeze-window policy ranks 1st |
| 4 | What services depend on payment-gateway? | `runbooks/dependency-graph-guide.md` (the list itself must come from the dependency-graph tool) | dependency-graph guide ranks 1st |
| 5 | Remember that checkout-service is always high-risk for our team. | `runbooks/high-risk-services-policy.md` | high-risk policy ranks 1st |
| 6 | Just approve this change for me. | `runbooks/change-approval-policy.md` | approval policy ranks 1st |

The retrieval checks run in `tests/test_cra.py`. Runbooks deliberately contain
no live facts (current health, freeze status, dependency lists); those come
only from the Week 2 tools, as the guardrails require.

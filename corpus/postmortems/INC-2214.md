# Postmortem INC-2214: payment-gateway client library version mismatch

Service: payment-gateway. Change type: Dependency upgrade. Severity: SEV2. Date: 2026-03-03.

## Summary

payment-gateway upgraded a shared client library while one of its internal
callers still used the previous major version. Requests serialised by the old
version were rejected by the new one, and a share of refund and capture calls
failed for about 45 minutes until the upgrade was rolled back.

## Root cause

Client library version mismatch between payment-gateway and a caller. The
upgrade did not check which consumers were still on the old version.

## Action items

Check every caller's library version before upgrading a shared client. Stage
upgrades so both versions are accepted during the transition.

# Postmortem INC-2248: order-service order-splitting flag enabled in all regions at once

Service: order-service. Change type: Feature flag rollout. Severity: SEV2. Date: 2026-05-02.

## Summary

A flag that splits multi-warehouse orders was enabled in every region at the
same time instead of through a canary. A race between the old and new code
paths created duplicate order records for about an hour until the flag was
turned off and the duplicates were cleaned up.

## Root cause

All-regions rollout of a flag that changed how orders were written, with no
canary and no duplicate detection.

## Action items

Canary flags that change write paths in one region first. Add duplicate order
detection before enabling order-splitting again.

# Postmortem INC-2255: auth-service connection pool reduced too aggressively

Service: auth-service. Change type: Infra change. Severity: SEV1. Date: 2026-05-10.

## Summary

auth-service's database connection pool was reduced to free database
capacity. At the morning login peak, authentication requests queued waiting
for connections. Web and mobile logins failed for about 30 minutes, and
checkout, which calls auth-service, failed for signed-in users.

## Root cause

Connection pool size reduced too aggressively, sized from off-peak usage.

## Action items

Size connection pools from peak load. Remember that auth-service sits upstream
of checkout and both frontends, so its failures have a wide blast radius.

# Postmortem INC-2289: checkout-service retry timeout set too low under load

Service: checkout-service. Change type: Config change. Severity: SEV2. Date: 2026-07-18.

## Summary

A config change shortened checkout-service's retry timeout for downstream
calls to reduce tail latency. Under load, retries gave up before slow but
healthy responses arrived, and checkout error rates rose for about 25 minutes.

## Root cause

Retry timeout set too low under load. The value was tested at normal traffic
only. The change resembled INC-2201, a timeout reduction on the same service,
but the earlier incident was not consulted during review.

## Action items

Review timeout and retry changes on checkout-service against INC-2201 and load
test them at 3x baseline, per the INC-2201 action items.

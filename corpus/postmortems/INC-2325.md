# Postmortem INC-2325: checkout-service autoscaling threshold changed before peak

Service: checkout-service. Change type: Infra change. Severity: SEV2. Date: 2026-08-30.

## Summary

checkout-service's autoscaling CPU threshold was raised to cut costs the day
before a weekend sale. When sale traffic arrived, new instances started too
late, and checkout latency spiked for about 20 minutes.

## Root cause

Autoscaling threshold changed pre-peak. The change was scheduled without
checking the upcoming traffic calendar.

## Action items

Check the traffic and event calendar before capacity changes. Avoid scaling
changes to checkout in the days before a known peak.
